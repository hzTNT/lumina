# Lumina 微光影库

一个类似 Jellyfin 的局域网视频网站。零 npm 依赖，双击即用：把视频放进媒体库目录，在同一 Wi-Fi 下的手机、平板、电视或电脑上用浏览器打开即可观看。

> **源码仓库说明**：本仓库只包含源码，不包含 Node/FFmpeg 运行时、演示媒体、`data/` 和 `config.json`。开箱即用的完整便携版请到 [Releases](../../releases) 下载；从源码运行需要自行安装 Node.js 22+ 与 FFmpeg，并让 `node`、`ffmpeg`、`ffprobe` 在 PATH 中。

## 功能

- **电影 / 剧集自动识别**：按文件名解析标题、年份、季集（`S01E02`、`1x02`、`第 2 集`、`EP02` 等）。
- **海报墙与详情页**：优先使用同目录的 `poster.jpg`、`fanart.jpg` 等图片，没有时自动从视频截帧生成。
- **两种播放方式**：
  - MP4（H.264 + AAC/MP3）等浏览器原生支持的格式直接播放，支持拖动进度、秒开。
  - MKV / HEVC / 其他兼容性较差的格式自动走按需 HLS 转码，首段几秒内出画，可任意拖动。
- **字幕**：自动发现同名字幕（`.srt` / `.ass` / `.vtt`，支持 `电影名.zh.srt` 这种语言后缀），也会提取视频内嵌文本字幕；自动转成浏览器可用的 WebVTT。
- **续播**：每 10 秒记录一次进度，关掉浏览器再打开可继续观看，看完自动标记。
- **收藏**：每个账号可以收藏喜欢的电影和剧集；卡片或详情页点一下心形按钮即可，收藏页按加入时间倒序排列。收藏按账号独立保存，并继续受媒体库权限与年龄限制过滤。
- **多端适配**：桌面侧栏布局，手机底部导航，全屏播放器、画中画、键盘快捷键。
- **媒体库管理**：设置页可添加/删除媒体库，为每个库设置访问成员和最低年龄，保存后自动重新扫描。
- **账号与权限**：首次启动创建管理员，支持开放/关闭自助注册；管理员与成员分级授权，设置、扫描、用户管理仅管理员可用。
- **年龄限制**：电影/剧集支持 0 / 7 / 13 / 16 / 18 分级，成员只能看到并播放自己实际年龄范围内的内容；支持“未分级”开关。每个媒体库还可以单独设置最低年龄。
- **独立观看进度**：每个账号保存自己的续播位置，换账号不会互相覆盖。
- **个人资料**：所有账号都能修改显示名称和头像；成员修改出生日期需要管理员确认，避免绕过年龄限制。
- **生日祝福**：注册时填写出生日期，生日当天登录会在首页收到一条可关闭的祝福横幅。

## 快速开始

1. 双击 `start.bat`（如果服务已经在运行，它会直接打开浏览器，不会重复启动）。
2. 浏览器会自动打开 `http://127.0.0.1:8096`；如果没有自动打开，手动访问即可。
3. **首次访问**会要求创建管理员账号（用户名 + 密码，至少 6 位，并填写出生日期），创建后自动登录。
4. 把视频复制到 `media` 目录（或任意子目录），点右上角的“重新扫描”按钮。
5. 在手机/电视上访问启动窗口中显示的局域网地址，例如 `http://192.168.1.100:8096`，用同一个账号登录。

> 电脑和手机需要连接同一个局域网。Windows 首次启动时如弹出防火墙提示，请允许“专用网络”访问。
>
> **从源码运行**：安装 Node.js 22+ 和 FFmpeg，确认 `node`、`ffmpeg`、`ffprobe` 在 PATH 中，然后在项目目录执行 `node server/index.js`。

## 账号、权限与年龄限制

- **管理员**：可以管理媒体库、扫描片库、管理用户和修改年龄分级；不受年龄与媒体库限制。
- **成员**：只能浏览和播放自己可见的内容；可以修改自己的显示名称、头像、密码和观看进度；出生日期变更需管理员确认；看不到设置与扫描入口。
- **用户名**：创建后不可修改；需要换用户名时只能新建账号。显示名称可以随时修改。
- **添加成员**：管理员进入 **设置 → 用户与权限**，填写用户名、显示名、初始密码和出生日期，并设置角色与“允许未分级内容”；用户列表会显示每个人的当前年龄。
- **自助注册**：同一位置可以开放/关闭注册。开放后，登录页会出现“注册一个”；注册时填写出生日期，系统据此计算可观看年龄，生日当天还会显示生日祝福。新账号默认为成员，管理员之后可修改或审批出生日期。
- **个人资料**：点击右上角头像 → **个人资料**，可以更换头像、修改显示名称和出生日期。显示名称与头像立即保存；成员修改出生日期后会进入“待管理员确认”，管理员在 **设置 → 用户与权限** 中同意后才会生效。管理员自己的出生日期修改即时生效。
  - 头像支持 JPG / PNG / WebP / GIF，单张不超过 10MB，浏览器会先压缩；服务端保存到 `data/avatars/`。
- **实际可观看年龄**：按出生日期计算实龄，并以 18 岁为上限；管理员始终为全部内容。
- **未分级内容**：默认允许；关闭后，该账号看不到没有分级的电影/剧集。管理员可以为单部影片或整部剧集设置分级。
- **媒体库权限**：每个库可设为所有成员、指定成员或仅管理员可见，并可设置成员最低年龄；影片自身的分级限制会继续叠加。

分级的来源优先级从高到低：

1. 管理员在详情页手动设置（保存到 `data/ratings.json`）。
2. 同目录的 `电影名.rating` 文件，内容如 `18`。
3. 同目录 `.nfo` 中的 `<mpaa>`、`<customrating>` 或 `<certification>`。
4. 文件名或所在文件夹中的标签，例如 `(2024) [18+]`、`PG-13`、`辅导级`。

支持 `0`、`7`、`13`、`16`、`18` 五档，以及“未分级”。

## 管理媒体库

推荐把视频放在任意磁盘，然后在网页里添加媒体库：

1. 打开左下角 **设置**。
2. 点 **添加媒体库**，填入名称和路径；路径可以是绝对路径，例如 `D:\Movies`，也可以是相对于 Lumina 根目录的路径，例如 `./media`。
3. 按需设置：
   - **访问权限**：`所有成员`、`指定成员` 或 `仅管理员`。
   - **最低年龄**：`不限`、`7+`、`13+`、`16+`、`18+`。成员的实际年龄低于该值时，整个库都不可见、不可播放。
   - 选择“指定成员”后，勾选可以访问该库的账号。
4. 点 **保存并扫描**。每个媒体库的影片仍会继续受单部影片的年龄分级限制。

管理员始终可以访问所有媒体库。也可以直接编辑 `config.json` 的 `libraries` 数组，保存后重启服务或点“重新扫描”。旧版配置里的 `mediaDirs` 会在启动时自动迁移为同名的媒体库，并继续保留用于兼容。

> 如果保存时提示“媒体库设置已在其他页面更新”，说明另一个设置页已经改过配置，刷新当前页后再保存。至少需要保留一个启用的媒体库，避免误操作把片库清空。

## 收藏

登录后，在电影或剧集卡片右下角、或详情页操作栏点 **心形** 按钮即可收藏；再点一次取消。左侧（手机底部）的 **收藏** 页面会按加入时间列出所有收藏。

收藏数据保存在 `data/favorites.json`，按账号隔离。账号的媒体库权限或年龄范围变化后，不可见的收藏会自动从列表隐藏；重新可见时会再次出现。

## 目录结构

```
lumina/
├─ start.bat              双击启动
├─ config.json            首次运行自动生成
├─ media/                 默认媒体目录（可删除示例视频）
├─ data/                  扫描结果、账号、分级、海报/字幕缓存、转码分片
├─ server/                Node 后端（无第三方依赖）
│  ├─ index.js            HTTP 服务、API、会话与权限校验
│  ├─ library.js          扫描、媒体库、播放信息、HLS 分片、分级过滤
│  ├─ users.js            账号、密码、会话、角色与年龄规则
│  ├─ ratings.js          年龄分级解析与标签识别
│  ├─ ffmpeg.js           ffprobe / ffmpeg 封装
│  ├─ subtitles.js        字幕发现与 WebVTT 转换
│  ├─ config.js           配置读写
│  └─ util.js             文件名解析等工具
├─ public/                原生 HTML / CSS / JS 前端
├─ runtime/node.exe       随项目附带的 Node.js
├─ bin/ffmpeg.exe         随项目附带的 FFmpeg
├─ bin/ffprobe.exe
└─ tools/                 接口冒烟测试（smoke.mjs / auth-smoke.mjs）
```

## 支持的播放格式

| 文件 | 播放方式 |
| --- | --- |
| MP4 / M4V（H.264 + AAC/MP3） | 浏览器直连，支持 Range 拖动 |
| WebM（VP8/VP9/AV1 + Opus/Vorbis） | 浏览器直连 |
| MKV、HEVC、AVI、TS、MOV 等 | 按需 HLS 转码（H.264 + AAC） |

HLS 分片会缓存在 `data/transcode/`，重复观看同一段不会重复转码；超过 7 天的分片会自动清理。

## 字幕

支持两种来源：

- **外挂字幕**：与视频同目录、同文件名，例如
  - `星际漫游 (2024).zh.srt`
  - `太空孤航 - S01E01.ass`
  - `Subs/太空孤航 - S01E01.chs.srt`
- **内嵌字幕**：MKV 中的文本字幕轨会自动提取（图形字幕如 PGS 暂不支持）。

字幕编码支持 UTF-8、GB18030/GBK、Big5 自动识别。

## 配置说明

`config.json` 主要字段：

```json
{
  "serverName": "Lumina 微光影库",
  "port": 8096,
  "host": "0.0.0.0",
  "libraries": [
    {
      "id": "lib_example001",
      "name": "电影",
      "path": "D:\\Movies",
      "enabled": true,
      "access": "all",
      "userIds": [],
      "minAge": 0
    }
  ],
  "scanOnStart": true,
  "scanIntervalMinutes": 30,
  "transcode": {
    "enabled": true,
    "maxHeight": 1080,
    "segmentSeconds": 6,
    "crf": 23,
    "preset": "veryfast"
  }
}
```

- `host` 保持 `0.0.0.0` 才能被局域网其他设备访问。
- `libraries` 是媒体库列表；`access` 为 `all` / `selected` / `admins`，`userIds` 在 `selected` 时生效，`minAge` 为成员最低年龄。
- `maxHeight` 控制转码最高分辨率；低性能机器可改为 `720`。
- 修改 `port` 后记得同步防火墙规则。

账号保存在 `data/users.json`，手动分级保存在 `data/ratings.json`，观看进度保存在 `data/progress.json`。备份或迁移时连同 `data/` 一起复制即可；删除 `data/users.json` 会回到首次创建管理员的流程。

## 常见问题

**手机打不开？**

- 确认手机和电脑在同一网段；
- 确认启动窗口显示的局域网 IP 正确；
- 在 Windows 防火墙中允许 Node.js 或 8096 端口的专用网络入站；
- 部分路由器开启了“AP 隔离”，需要关闭。

**提示端口被占用？**

8096 已被其他程序（可能是另一个 Lumina 实例）占用。关闭旧窗口，或修改 `config.json` 里的 `port`。

**视频一直转圈 / 无法播放？**

- 查看启动窗口是否有 FFmpeg 报错；
- 确认 `bin/ffmpeg.exe` 与 `bin/ffprobe.exe` 存在；
- HEVC 10bit、杜比视界等格式在部分设备上兼容性较差，可尝试更换片源或降低 `maxHeight`。

**没有海报？**

在视频同目录放置 `poster.jpg`（竖版）和 `fanart.jpg`（横版），文件名与视频相同或使用 `poster` / `folder` / `cover`，然后重新扫描。

## 开发与测试

```bat
runtime\node.exe server\index.js
runtime\node.exe tools\smoke.mjs
runtime\node.exe tools\auth-smoke.mjs
```

`tools/smoke.mjs` 会对本机 8096 端口的 API 做一轮冒烟测试（健康检查、登录、媒体库、播放信息、Range、海报、字幕、HLS、进度、设置）。默认使用 `admin` / `secret123` 登录；如果账号不同，先设置环境变量：

```bat
set LUMINA_USER=你的用户名
set LUMINA_PASS=你的密码
runtime\node.exe tools\smoke.mjs
```

`tools/auth-smoke.mjs` 用于验证注册、角色权限、年龄过滤与未分级开关；它要求全新的 `data/`（没有账号），否则会直接退出，避免在正式片库里创建测试账号。两个脚本都会写入测试数据，正式使用前请清理对应的测试账号、分级和进度。

## 安全提醒

Lumina 面向家庭局域网。账号密码只保存在本机，密码使用 scrypt 加盐哈希，登录状态通过 HttpOnly Cookie 维持；会话保存在 `data/sessions.json`，服务重启后仍保持登录（有效期 30 天）。但 Cookie 按地址区分：`127.0.0.1`、`localhost` 和局域网 IP 属于不同地址，在其中一个地址登录不会同步到另一个，请在每台设备上固定使用同一个访问地址。请仍然不要把 8096 端口直接暴露到公网，也不要在公共 Wi-Fi 上开放。如需外网访问，请使用 VPN 或带额外认证的反向代理。
